## 它是什么

知几·关系智顾（zhiji-relationship）是一个面向情感与人际决策的 Codex Skill，把两套完全不同的视角整合进同一个对话入口：

| 来源 | 贡献 |
|------|------|
| **狗头军师** | 40 份跨学科知识文档、五步分析流程、安全边界、按需加载架构 |
| **童锦程.skill** | 5 个核心心智模型、9 条决策启发式、直白反心灵鸡汤表达 DNA |

你可以只用默认模式——它接住情绪、还原事实、给出有理由支撑的建议；
你也可以加一句「童锦程怎么看」——它用直白短句帮你绕开自我欺骗。

## 效果示例

### 默认模式

```
用户  ❯ 我喜欢他两年了，他对我忽冷忽热，现在他主动约我，我不知道该
         不该去。

知几  ❯ 两年，够长了。忽冷忽热的感觉会让人一直悬在那里，这本身就很
         消耗——先承认这个。

         事实层面：这次他主动约，可以是真的想靠近，也可以是无聊时的
         习惯性联系。区别在于：约的是有确定时间地点的具体邀请，还是
         随口一句"改天"？

         建议：去——但带着观察目的。见面时注意他是否把注意力放在你
         身上，结束时他是否主动提下次。两件事都没有，那个答案已经给
         你了。
```

### 风格层（童锦程模式）

```
用户  ❯ 用童锦程的方式帮我看：前任突然说想我了，我要回应吗？

知几  ❯ 兄弟，问你自己一件事：她说"想你了"这三个字，你第一反应是
         心跳，还是叹气？

         心跳是感情，叹气是习惯。这两件事差很多，知道吗？

         她现在联系你，不一定是想复合。可能只是某天晚上没事干，翻到
         你了。人性就是这样——你若还在原地，对她来说成本很低。

         你不用马上回。等一等，看她说第二句。能主动说清楚她要什么的
         人，才值得你认真对待。
```

## 安装

```bash
git clone https://github.com/1wu-davy-2/zhiji-relationship.git ~/.codex/skills/zhiji-relationship
```

在 Claude Code 中输入：

```text
使用 $zhiji-relationship 帮我梳理情绪、分析当前关系，并给出下一步建议。
```

首次使用时，它会询问你和对象的基本档案（MBTI / 评分 / 关系背景 / 目标 / 情绪强度）。不知道的可以留空，也可以直接讲故事。

## 设计原则

来自狗头军师的核心设计立场，知几完整继承：

1. **先接住人，再解决事。** 情绪没被看见时，最正确的建议也可能无法执行。
2. **行为比标签可靠。** 不凭 MBTI、性别或一次聊天记录替对方读心。
3. **互惠比追到更重要。** 减少内耗、保留尊严与未来选择权同样是成功。
4. **策略必须说明代价。** 可以讨论撒娇、推拉和表达包装，但同时交代适用条件与长期成本。
5. **同意和退出权不可绕过。** 明确拒绝不是需要破解的障碍。
6. **危险情境先保安全。** 暴力、胁迫、跟踪和自伤风险不能用普通恋爱话术处理。

## 诚实边界

**能做的：**
- 理清情绪，还原事实，识别关系中的互惠与信号
- 给出有理由支撑的行动建议、可发送的话术和对话演练
- 在明确拒绝时停止推进，提供体面退出方案

**做不到的：**
- 替代心理咨询、医疗诊断或法律意见
- 保证追到某个具体的人——没有任何方法论能绕开另一个自由意志
- 商业、职场或纯创业决策（tong-jincheng-skill 对商业场景数据不足）
- 协助任何形式的操控、跟踪、胁迫或绕过同意的行为
