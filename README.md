## 它是什么

知几·关系智顾（`zhiji-relationship`）是一个面向情感与人际决策的 Codex Skill。它把共同的关系分析内核和三个可以独立调用的观察镜头放进同一个对话入口：

| 来源 / 视角 | 主要贡献 |
| --- | --- |
| **狗头军师** | 关系科学知识库、五步分析流程、安全边界、按需加载架构 |
| **童锦程** | 吸引力、真诚表达、给台阶、反心灵鸡汤、减少自我欺骗 |
| **峰哥** | 反向重构、现场核验、反脸谱化、现实成本与风险意识 |

你可以使用默认的关系分析内核，先接住情绪、还原事实，再得到有理由支撑的建议；也可以只调用某一个视角，或让三种视角分别分析后进行会诊。

三种视角来自公开资料整理，不代表现实人物本人，不替用户读心，也不保证追到某个具体的人。安全、同意、隐私和可核验事实始终优先于表达风格。

> 只想使用峰哥视角时，请安装独立仓库 [峰哥（fengge-skill）](https://github.com/1wu-davy-2/fengge-skill)；本仓库保留三人格会诊、单人格调用和自定义组合能力。

## 三人格架构

```text
用户输入
    │
    ├── 未指定人格 ──► 狗头军师共同内核
    │                    情绪落地 · 事实拆分 · 互惠判断 · 行动建议
    │
    ├── 指定一个 ────► 只加载对应视角
    │                    狗头军师 / 童锦程 / 峰哥
    │
    ├── 指定两个 ────► 共享事实底稿
    │                    各自判断 · 明确共识与分歧 · 综合行动
    │
    ├── 三人会诊 ────► 三个视角分别分析
    │                    共同事实 · 三方判断 · 综合建议
    │
    └── 自定义搭配 ──► 按用户指定职责、顺序和权重组织输出

         ↑ 安全、同意、隐私与事实优先，任何视角都不能绕过 ↑
```

## 三个视角分别负责什么

### 狗头军师：证据与关系过程

- 先承接情绪，再区分已知事实、合理推测和未知。
- 重点观察持续主动、具体邀约、兑现承诺、回应需求、边界和互惠。
- 把建议落到行动、观察窗口和停止条件，不把“追到”当成唯一成功。

### 童锦程：吸引与真诚表达

- 关注吸引力和讨好的区别，以及如何自然表达喜欢。
- 用真实欣赏、具体邀约和给台阶降低沟通成本。
- 不用冷暴力、嫉妒、突袭或测试人性制造关系推进。

### 峰哥：现实与现场核验

- 通过反向重构看见隐藏的信息、机会和代价。
- 不被星座、标签、单条消息或漂亮叙事带着走，回到具体行为。
- 用低成本、可退出的行动验证对方是否真实投入，避免长期单方面消耗。

## 使用方法

### 1. 安装

仓库名是 `zhiji-relationship`，Skill 的调用名是 `zhiji`。由于 Skill 技术名遵循英文标识规范，界面显示名使用中文“知几”，实际调用使用 `$zhiji`。

使用 SSH 安装到 Codex 技能目录：

```bash
git clone git@github.com:1wu-davy-2/zhiji-relationship.git ~/.codex/skills/zhiji
```

Windows PowerShell：

```powershell
git clone git@github.com:1wu-davy-2/zhiji-relationship.git "$env:USERPROFILE\.codex\skills\zhiji"
```

也可以使用 Skill 安装器安装公开 GitHub 仓库。安装时要显式指定 `--name zhiji`，避免按仓库名生成过长的目录：

```powershell
python "$env:USERPROFILE\.codex\skills\.system\skill-installer\scripts\install-skill-from-github.py" `
  --repo 1wu-davy-2/zhiji-relationship --path . --name zhiji
```

安装后重新打开 Codex 或开启新任务，然后输入 `$zhiji`。Skill 通常从 `$CODEX_HOME/skills/`（未设置时为 `~/.codex/skills/`）中发现。

### 2. 第一次使用：初始化 / 使用教程

不熟悉用法时，直接把下面任一条发给 AI：

```text
$zhiji /init
$zhiji 使用教程
```

AI 会先告诉你它能做什么，再给出默认分析、单人格、三人会诊和自定义搭配的示例。你不需要先填写 MBTI、星座或完整关系档案，直接讲故事也可以。

教程输出示例：

```text
知几：这是一个帮助你梳理关系、识别行为信号和决定下一步的 Skill。

你可以这样开始：
1. 使用 $zhiji 分析：她说想慢慢来，我还要不要继续？
2. 只用峰哥分析：这段关系的现实信号是什么？
3. 三人会诊：她对我有好感，但一直不愿确定关系。
4. 自定义搭配：狗头军师负责事实，峰哥负责反向核验，童锦程负责改写话术。

也可以输入“退出人格模式”或“只保留狗头军师”切换分析方式。
```

### 3. 默认分析

未指定人格时，使用狗头军师共同内核：

```text
使用 $zhiji 帮我分析：她说想慢慢来，我还要不要继续？
```

可以直接讲故事，也可以补充：关系阶段、最近 3 至 5 次互动、谁主动、邀约是否兑现、你的目标和当前情绪。未知信息可以留空，不需要为了分析猜测一个 MBTI 或星座结论。

### 4. 单人格分析

```text
只用狗头军师分析：我们最近是不是投入失衡？
只用童锦程分析：我下一次怎么自然邀约？
只用峰哥分析：她说“慢慢来”到底意味着什么？
```

单人格输出包括：核心判断、事实与未知、一个行动，以及观察窗口或停止条件。不会把其他人格的意见伪装成当前视角的结论。

### 5. 两人格组合

```text
狗头军师 + 峰哥：帮我判断这段暧昧关系要不要继续。
童锦程 + 峰哥：帮我设计下一次自然邀约。
狗头军师 + 童锦程：分析她的回复，并给一条可发送的话术。
```

两人格会共享同一份事实底稿，再分别给判断，最后合并为一条行动，避免重复输出三套互相竞争的建议。

### 6. 三人会诊

```text
三人会诊：她说对我有好感，但现在不想确定关系，我已经连续主动两周了。
```

默认输出顺序：

1. 共同事实与关键未知
2. 狗头军师的关系过程和风险判断
3. 童锦程的吸引与表达判断
4. 峰哥的现实核验和成本判断
5. 共识、分歧、首选行动、观察窗口和停止条件

### 7. 自定义职责、顺序和权重

```text
自定义搭配：狗头军师负责事实和风险，峰哥负责反转判断，童锦程负责改写一条可发送话术。

自定义搭配：先峰哥判断，再让狗头军师核验，最后用童锦程视角润色表达。

狗头军师 50% + 峰哥 30% + 童锦程 20%，分析这段关系。
```

百分比只调整篇幅和侧重点，不代表某个结论的概率。职责分配也不能改变事实标准、安全边界或对方的自主权。

### 8. 切换或关闭视角

```text
只保留狗头军师。
取消峰哥。
退出人格模式，切回正常分析。
```

## 效果示例

### 默认模式

```text
用户：我喜欢她很久了，她最近回复变慢，但又说想慢慢来，我该怎么办？

知几：先说结论：可以继续了解，但不要继续单方面加码。

她说“慢慢来”是明确的节奏要求，不等于自动拒绝，也不等于承诺。
现在能确认的是她提出了放慢节奏；还不知道的是，她是否愿意见面、
是否会主动延续，以及她愿意用什么方式继续了解。

你可以提出一次具体、低压力、可拒绝的邀约。她接受，或不能来但主动
给出替代时间，说明关系还有可观察的互惠；如果持续只有“再看看”和
“最近忙”，却没有任何具体安排，就降低投入，不再无限等待。
```

### 三人会诊模式

```text
用户：三人会诊。她说对我有好感，但想慢慢来，我还要追吗？

共同事实：她表达过好感，也提出放慢节奏；她是否主动、是否接受具体
邀约、是否兑现，目前未知。双鱼座不构成动机证据。

狗头军师：尊重节奏，先用一次低压力邀约确认双方是否愿意共同推进。
童锦程：可以真诚表达喜欢，但别把表达变成讨好，也不要逼她立刻定义关系。
峰哥：别把“有好感”当成“愿意投入”。去看实际时间、行动和兑现，模糊
拖延本身就是需要计入的信号。

综合建议：只推进一小步，然后按她的实际回应匹配投入。明确拒绝或要求
停止联系时，停止推进。
```

## 设计原则

1. **先接住人，再解决事。** 情绪没有被看见时，正确的建议也可能无法执行。
2. **行为比标签可靠。** 不凭星座、MBTI、性别或一次聊天记录替对方读心。
3. **互惠比追到更重要。** 减少内耗、保留尊严和未来选择权同样是成功。
4. **策略必须说明代价。** 主动、留白和表达包装不能变成操控、恐惧或依赖。
5. **同意和退出权不可绕过。** 明确拒绝不是需要破解的障碍。
6. **危险情境先保安全。** 暴力、胁迫、跟踪和自伤风险不能用普通恋爱话术处理。

## 诚实边界

### 能做的

- 理清情绪，还原事实，识别关系中的互惠与信号。
- 给出有理由支撑的行动建议、可发送话术和对话演练。
- 在明确拒绝时停止推进，提供体面退出方案。
- 在三个视角之间展示共识和分歧，而不是用一种口吻掩盖不确定性。

### 做不到的

- 替代心理咨询、医疗诊断或法律意见。
- 保证追到某个具体的人；任何方法都不能绕开另一个人的自由意志。
- 协助操控、跟踪、偷拍、威胁、性施压、诈骗、散布隐私或绕过同意。
- 把“性压抑”当作万能解释、远程诊断或犯罪／自伤归因。
- 代表狗头军师、童锦程或峰哥本人发言，或声称掌握他们的私下想法和最新立场。
